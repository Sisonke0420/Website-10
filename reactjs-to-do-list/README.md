# Daymark

A calm, responsive daily to-do list built with React and Vite. Add, edit, complete, and delete tasks; filter the list by status; track daily progress; and use the calendar to schedule plans for future dates. Tasks are saved in your browser between visits.

## Planning by date

Choose **Calendar** above your task list to browse months and select a day. Add tasks while a date is selected to schedule them for that day. Days with plans are marked on the calendar, and selecting a date shows its tasks and progress.

## Getting started

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — check the project with ESLint
